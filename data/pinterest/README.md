# Pinterest Search Results

This directory stores the output from Pinterest Search Scraper.

## File Formats

- `pinterest_search_*.json` - JSON format with full data structure
- `pinterest_search_*.csv` - CSV format for Excel analysis (UTF-8 BOM encoded)

## Structure

Results are automatically saved here when `saveToFile: true` is set in the API request.

Each file is timestamped for easy identification.
